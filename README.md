# Mania EXT 转谱器

把 osu!mania 谱面**改造成另一种键数**的浏览器工具：搜索下载或拖入 `.osz`，选一种转谱算法生成新难度，再打包成 osz 下载。

![界面预览](assets/preview.png)

## 怎么用

### 1. 先设参数（右侧「转谱设置」）

- **目标键数**：加到几 K（6K～10K）。
- **源键数过滤**：只转勾选的键数；键数已达到目标的难度会自动跳过。

### 2. 两种输入方式，任选其一

**搜索下载**

1. 输入曲名 / 艺术家 / 谱师 / 难度名，回车搜索（多个词用空格分隔，表示「且」）。
2. 想按谱师找图，把右侧下拉切到「谱师」，填用户名，例如 `_IceRain`。
3. 卡片上点「下载并转换」，或「仅下载」只要原始 osz。
4. 下载区可选 **不含视频 / 含视频**。

**上传 osz**

1. 把 `.osz` 拖进虚线框（支持多个），或点击选择文件。
2. 点「开始转换」。

> 上传的任务会立刻执行；搜索下载的任务排在队列里依次跑，头部显示「N 个进行中 · M 个排队」。

### 3. 拿结果

转换完成后自动下载，产物名形如：

```
<艺术家> - <标题> (<原作者>) [EXT 10k].osz
```

原 osz 里的音频、背景、视频、原难度全部保留，只额外追加新难度（难度名后缀 `[EXT 10k]`，creator 标为 `<原作者> (EXT 10k)`）。任务卡片里可以「再次保存 osz」。

已是转谱的难度、非 mania 难度、占位谱（note ≤ 20 且时长 ≥ 6 分钟）会自动跳过，并在任务里写明原因。

## 说明

- 单文件发布（`dist/mania-converter.html`，约 260 KB），可直接双击离线打开；转换全在浏览器内完成，文件不会上传。
- 谱面数据与 osz 均来自 [Sayobot](https://osu.sayobot.cn/)，本项目与 Sayobot 无隶属关系；下载源不可用时请改用本地上传。
- 结果带随机性，同一张谱面多次转换不会完全一样。
